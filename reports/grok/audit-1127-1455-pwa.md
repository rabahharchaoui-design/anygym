# Grok pwa audit

- MAJOR src/hooks/runEngine.ts:114 — The phone is out of room. The exercise photo cache is holding the catalog (about 15 MB) and the voice cache about 1.5 MB. A basement run's autosave throws QuotaExceededError. This handler marks the save failed and writes the same row again. `purgeOnQuotaError` runs only inside the service worker when one of its own cache puts fails, and the background save writes those caches from the page (`src/lib/photoWarm.ts:51`) and swallows the error. Nothing deletes the caches, so every retry fails, Hold End fails the same way, and if iOS closes the app the run since the last successful save is gone. Logging a set fails and retries the same way. Smallest fix: on QuotaExceededError from a run or workout save, delete the `exercise-photos` and `run-voice` caches and retry that save once.
- MINOR src/pwa.ts:13 — You open the app while a new version is still installing, tap Start, and the pocket note or the 3-2-1 is up (the count runs about 3.6 seconds, `src/screens/run/Countdown.tsx:8`). The update reaches waiting. `appActivity` sees no workout row and no run row, and `liveRunInMemory` is false because the probe is only `live !== null` (`src/hooks/useRunEngine.ts:7`). `runEngine.start` sets that after GO (`src/screens/run/RunStart.tsx:118`, `src/hooks/runEngine.ts:278`). The page reloads and you are back on the start screen. Smallest fix: from the moment the countdown starts until `start` or cancel, report a run from `appActivity`, and apply the reload only after that check.
- MINOR src/components/exercise/DemoPicture.tsx:19 — Gym Wi-Fi is connected and has no internet, so `navigator.onLine` stays true and `usePhotos` returns `net` (`src/hooks/usePhotos.ts:19`). An exercise photo this phone has not cached yet is drawn with this `img` and no `onError`. The fetch fails. The hero is a broken picture, and "Photos show when you are back online" stays hidden because that line runs only for `kind === 'none'` (`src/components/exercise/ExerciseSheet.tsx:37`). Smallest fix: on a failed image load, drop that frame and show the same empty state as the offline path.
