2. **Retrying multiple failed rows skips sets as their slots shift.** [rowLog.ts:171](/Users/rabah/projects/anygym/src/screens/workout/rowLog.ts:171) reloads each failed draft using its original slot key. Successfully retrying the first row removes its slot, shifting later drafts; subsequent iterations therefore retry the wrong row or skip it. `retryFailed()` can return true while failed sets remain. **Exact fix:** for each captured failure, locate the current draft and key by stable `f.draft.id` in `sessionDrafts()`, then save and submit that draft using its current key.
