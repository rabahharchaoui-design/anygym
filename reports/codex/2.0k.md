1. **Pending weights can still be lost across tabs.** [src/lib/drafts.ts:282](/Users/rabah/projects/anygym/src/lib/drafts.ts:282): IndexedDB authority is tracked only in the current tab’s `hydrated` map. If A’s localStorage write fails and IndexedDB saves its weight, an already-open, unhydrated B can later edit another row and overwrite both stores with stale localStorage data. **Exact fix:** route every phone draft write through the transactional per-row merge in `persistRows`; publish only that merged snapshot to localStorage.

2. **Retry can save the older failed correction and discard the newer one.** [src/db/mutations.ts:314](/Users/rabah/projects/anygym/src/db/mutations.ts:314): two held operations are ordered by `at`, which is monotonic only within each tab. If both journal writes fail and the later tab has an earlier timestamp, Retry selects the older correction and journals it covering both held IDs. **Exact fix:** persist the predecessor IDs on held operations too, and determine supersession from those relationships rather than timestamps; preserve them through fallback storage and backup.
